# So-ARM シリーズ キャリブレーションツール — Windows ガイド

Windows 10 / 11 向けです。インストールからサーボのフルキャリブレーションまでを扱います。

> ⚠️ **互換性：本ツールは現在、Feetech（STS3215 シリーズ）サーボのみに対応しています**。レジスタテーブルと xdat 形式は Feetech STS3215 向けに設計されています。他社製・他モデルについては互換性を保証しません。

---

## 1. 動作要件

| 依存関係 | バージョン | 備考 |
|-----------|---------|-------|
| Python | >= 3.8 | 3.10 以上を推奨。[python.org](https://www.python.org/downloads/) からダウンロード |
| PySide6 | >= 6.0 | GUI フレームワーク |
| pyserial | >= 3.5 | シリアル通信 |
| OS | Win10 / Win11 | エディションは問いません |

## 2. Python のインストール

1. <https://www.python.org/downloads/> にアクセスします
2. Python 3.10 以上のインストーラーをダウンロードします
3. インストール時に **「Add Python to PATH」にチェック** を入れます（入れないとターミナルで python が見つかりません）

確認：

```bash
python --version
```

## 3. 依存関係のインストール

システムの Python を汚さないよう、仮想環境にインストールします：

```bash
cd SO-ARM101-ServoController
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

> ⚠️ **仮想環境は一度だけ作成してください**。再実行すると環境がリセット／上書きされます（インストール済みの依存関係が消去されます）。以降は毎回 `activate` するだけでかまいません。

> 有効化すると、プロンプトに `(.venv)` が表示されます。

## 4. 環境の確認

```bash
python setup.py
```

`[OK] 环境检查通过，可以运行项目` と表示されれば、環境は準備完了です。

## 5. ハードウェアの接続

1. USB-シリアルアダプター（CH340 / CP2102）を接続します
2. サーボコントローラー（ロボットアームの制御基板）を接続します
3. サーボに電源を供給します（標準版は DC 5V 5A、Pro 版は DC 12V 5A）

デバイスマネージャーで COM ポートを確認します（`Win+X` → デバイスマネージャー）：

```
ポート (COM と LPT)
  └─ USB-SERIAL CH340 (COM3)     ← サーボ用ポート
```

> 起動時に選択するため、**COM 番号を控えておいてください**。

## 6. GUI の起動

```bash
python main.py
# または
python -m src.gui.factory_calibration_tool
```

> **Windows でのインストール不要の方法**：`dist\SO-ARM101-ServoController.exe` をダブルクリックしてください。対象マシンに Python は不要です。再ビルドは `pyinstaller -y SO-ARM101-ServoController.spec` で行います。

またはポートを指定します（使用中の場合）：

```bash
python -m src.gui.factory_calibration_tool --port1 COM3 --port2 COM4
```

利用可能なポートを一覧表示する場合：

```bash
python -m src.gui.factory_calibration_tool --list-ports
```

## 7. インターフェースの操作手順

### 7.1 サーボキャリブレーションタブ

1. トップバーでリーダー／フォロワーアームのポートを選択 → サーボを自動スキャン（ID 1-6）。
2. よく使うボタン：
   - **リーダー／フォロワーアーム中心キャリブレーション**：LeRobot キャリブレーションウィザードを開きます
     - 左列：6 つのサーボすべてのリアルタイムモニター（ID / Pos / スライダー）
     - **中位の記録を開始**（オレンジ色に変わる）→ アームを中位に配置 → **中位の記録を完了**
     - **範囲を記録**（緑色に変わる）→ 各関節を一端から他端まで、**グリッパーも含めて**動かす → もう一度クリックして停止
     - 6 つの関節すべてが完了すると、キャリブレーションファイルが自動保存されて既存ファイルを上書きし、オフセットとリミットがサーボ EEPROM に書き戻されます
   - **リーダー／フォロワーアーム中心テスト**：トルクを有効にして中心へ移動し、検証
   - **リーダー／フォロワーアーム モーター無効化**：トルクを無効にして手動で動かせるようにします

> ⚠️ 両方のアームを同じ行程で動かしてください。そうしないと、遥操作時にフォロワーの動きがリーダーと一致しません。

### 7.2 単一サーボ制御タブ

- 各行：ID / Pos / スライダー / L（目標値）
- **Pos とスライダーは双方向にバインド**：スライダーをドラッグすると Pos が更新され、Pos に入力するとスライダーが移動して直ちにコマンドが送信されます
- コマンドはスライダーを離したときに送信され、ドラッグ中に連続して送信されることはありません
- サーボの動作中、スライダーと Pos は実際の現在位置に追従します
- ⚡ トルク / 🎯 中位 / 🧹 リミット解除 はそのサーボ単体に作用します

### 7.3 FT デバッガータブ

- **シリアル接続**：ポート、ボーレート（既定 1M）を選択
- **サーボのスキャン**：オンラインのサーボを検出
- **パラメータの読み取り**：すべてのレジスタ（EEPROM + SRAM）を読み取り
- **パラメータテーブル**：56 個のレジスタをすべて表示する 5 列、**行選択の連動でアドレス／長さ／値を入力**
- **書き込みポップアップ**：成功時は緑の「✅ 書き込みに成功しました」、失敗時は赤の「❌ 書き込みに失敗しました」（理由付き）
- **位置制御**：
  - **スライダー**で目標位置（0-4095）を調整。値ボックスはリアルタイムに更新。ボックスへ直接入力も可能
  - 移動後、トルクをオフにするよう促します
- **ボーレート／工場出荷時リセット**：ボーレートの変更、工場出荷時リセット
- **xdat パラメータ（EEPROM のみ）**：
  1. `💾 現在のサーボを保存`：現在のサーボの EEPROM パラメータを xdat ファイルに保存
  2. `📂 xdat を開く`：バックアップファイルを読み込み
  3. `📤 サーボへ復元`：バックアップをサーボに書き戻し

### 7.4 リモート操作

> ⚠️ **方向：リーダーアームがフォロワーアームを制御します**。リーダーアーム（マスター）はサーボの角度を読み取るだけで、フォロワーアーム（スレーブ）が同期されます。両ポートで一致するサーボ ID が必要です。

- トップバーの `🎮 リモート` ボタン：リーダーが読み取り → フォロワーが制御（同じ ID のサーボ）
- もう一度クリックするとリモート操作を停止します

## 8. トラブルシューティング

| 問題 | 解決策 |
|---------|----------|
| シリアルポートが表示されない | デバイスマネージャーでドライバーを確認。別の USB ポートを試す。CH340 ドライバーをインストール |
| ポートが使用中 | シリアルモニターを閉じる。ツールを再起動 |
| 中国語のテキストが空白 | システムには Microsoft YaHei があります。表示が崩れる場合は CJK フォントをインストール |
| サーボが見つからない | 電源／配線を確認。1M ボーであることを確認 |
| ポートを開く際の PermissionError | COM ポートを他のプロセスが占有していないことを確認 |
